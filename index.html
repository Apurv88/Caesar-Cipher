🔐 Caesar Cipher
Encrypt & decrypt messages using the Caesar Cipher algorithm.
How it works
Encrypt: C = (P + K) mod 26     Decrypt: P = (C − K + 26) mod 26
P = Plaintext index (A=0 … Z=25)  ·  K = Shift Key  ·  C = Ciphertext index
